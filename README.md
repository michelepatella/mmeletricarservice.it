# [mmeletricarservice.it](https://mmeletricarservice.it)
A modern and serverless full-stack web application, for an Italian **car workshop** and **used cars dealership**.  

## 🚀 Features
- **Company Overview**: Introduction to the business, including mission, values and customer-centric philosophy.
- **Workshop Services**: Detailed list of services offered.
- **Used Cars Area**: Catalog of available used cars, shown through clickable cards. Each card links to a dedicated dynamic route with full details and image gallery.
- **Location & Contact**: Location and contact info, business hours and Google Maps embedding to improve search visibility.
- **SEO Optimization**: metadata to improve search visibility and
- **UX**: Responsive design, optimized both for mobile and desktop devices.

## 🔗 Pages & Structure
The application consists of multiple sections designed for both informational and functional purposes:
- **Home**: Landing page.
- **About Us**: About the company and history.
- **Our Values**: Values and mission of the company.
- **Services**: Introduction to the services page.
- **All Services**: List of services provided.
- **Used Cars**: Grid of available used cars, each one of them opens a dedicated page (/used-cars*id*) with defailts specs, multiple images and contact CTA.

Navigation is handled via an Anchor menu (on desktop devices) and Hamburger menu (on mobile devices).

## 🛠️ Tech stack
- **Frontend**: React.js
- **Backend as a Service (BaaS)**: Supabase (PostgreSQL, Storage)
- **Hosting**: Vercel
- **Styling**: Ant Design
